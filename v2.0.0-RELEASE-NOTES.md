## 🎉 Major Release: Complete Redesign with Interactive TUI

We're thrilled to announce **DGF v2.0.0**, a complete reimagining of the Direct Git Fetch tool. This release introduces a modern **interactive Terminal User Interface (TUI)** while maintaining full backward compatibility with the existing CLI. Whether you prefer visual browsing or command-line automation, DGF now supports both workflows seamlessly.

---

## ✨ What's New in v2.0.0

### 🖥️ Interactive Terminal UI (TUI) - The Main Event

- **Visual File Browser** - Navigate repository contents with an intuitive terminal UI featuring keyboard-driven navigation
- **Real-time Search** - Press `/` to filter files instantly as you type, with instant updates
- **Multi-select Capabilities** - Select multiple files/folders using Space, select all with `a`, unselect all with `u`
- **File Preview** - Preview text files before downloading with the `p` key
- **Icon Customization** - Toggle between emoji and ASCII icons with the `i` key to match your terminal theme
- **Breadcrumb Navigation** - Visual path indicator showing your location in the repository tree with back button support
- **Download Confirmation** - Confirm selections before initiating downloads
- **Clipboard Support** - Easily copy file paths to your clipboard
- **Live Progress Tracking** - Real-time progress bars for batch downloads

### 🔧 Configuration Management

New `dgf config` subcommand for persistent, user-friendly settings:
- `dgf config show` - Display all current settings
- `dgf config get <key>` - Get a specific configuration value
- `dgf config set <key> <value>` - Set and persist configuration
- `dgf config path` - Show the location of the config file

Configurable options:
- `token` - GitHub API token for private repositories
- `download_path` - Default download directory
- `ascii_mode` - Use ASCII icons instead of emoji
- `workers` - Number of parallel download workers

### 🤖 Agent/JSON Mode for Automation

New machine-readable output mode for integration with scripts and external tools:
- `dgf agent tree <url>` - Get repository tree structure as JSON
- `dgf agent download <url> <paths...>` - Download files programmatically with JSON output

### 📦 Git LFS Support

- **Automatic Detection** - Seamlessly detects Git LFS pointer files
- **Transparent Download** - Automatically downloads LFS-tracked files when available
- **Fallback Support** - Falls back to pointer file if LFS download fails

### ⚡ Download Improvements

- **Parallel Downloads** - Configurable worker pool for multi-threaded downloads
- **Recursive Folder Selection** - Download entire folder hierarchies
- **Progress Tracking** - Real-time progress tracking for batch downloads
- **Enhanced Error Handling** - Improved retry logic and error reporting
- **Syntax Highlighting** - Code files shown with syntax highlighting in preview mode

### 📚 Codebase Modernization

- **Complete Restructure** - Migrated from flat structure to organized `cmd/`, `internal/`, `pkg/` layout
- **Improved Modularity** - Clean separation of concerns: TUI, Config, Selection, Agent, and GitHub Client modules
- **Better Argument Parsing** - More robust and user-friendly command-line argument handling
- **Enhanced Help Text** - Comprehensive help messages with practical examples

### 📦 New Dependencies (for TUI)

- `bubbletea` - Modern terminal UI framework
- `lipgloss` - Terminal styling and formatting
- `bubbles` - Reusable UI components

---

## 🔄 Backward Compatibility

**v2.0.0 maintains full backward compatibility with v1.x CLI usage:**

```bash
# All v1.x commands continue to work
dgf https://github.com/user/repo -f code -o ./output
dgf -s github -u user -r repo -p src/ -f [pdf,jpg]
dgf --check -s github -u user -r repo -p path/to/file
dgf --print-tree -s github -u user -r repo
```

## 🛠️ Installation & Update

### Quick Install

```bash
# Download the installer
curl -LO https://raw.githubusercontent.com/NeerajCodz/dgf/main/dgf-installer.sh
chmod +x dgf-installer.sh

# Install system-wide (optional)
sudo ./dgf-installer.sh
```

### Automatic Updates

The installer now supports seamless updates:

```bash
# Re-run the installer to check and update
sudo ./dgf-installer.sh
```

### Uninstall

```bash
# Uninstall from default location
sudo ./dgf-installer.sh --uninstall

# Uninstall from custom directory
sudo ./dgf-installer.sh --uninstall /path/to/dir
```

### Token Support

For private repositories, provide a GitHub token:

```bash
# Via flag
dgf <URL> --token ghp_xxxxx

# Via environment variable
export GITHUB_TOKEN=ghp_xxxxx
dgf <URL>
```

## 🚀 Getting Started

### Interactive Mode (New Default)

```bash
# Start the interactive TUI
dgf

# Or start with a GitHub URL
dgf https://github.com/torvalds/linux
```

Then use keyboard shortcuts:
- `↑/↓` or `j/k` to navigate
- `Enter`/`l` to enter folders
- `Space` to select
- `d` to download
- `?` for help
- `q` to quit

### CLI Mode (Still Supported)

```bash
# Download all code files
dgf -s github -u user -r repo -f code

# Download specific formats
dgf -s github -u user -r repo -f [pdf,jpg,png]

# Check if a path exists
dgf -s github -u user -r repo --check -p path/to/file
```

## 🐛 Known Limitations & Notes

1. **LFS Downloads** - Large File Storage files require proper Git LFS setup; fallback to pointer file if unavailable
2. **Private Repositories** - Always provide a valid GitHub token for authenticated access
3. **Rate Limiting** - GitHub API rate limits apply; use parallel worker configuration wisely
4. **TUI Terminal Support** - Requires a capable terminal emulator; use `ascii_mode` on limited terminals

---

## 📊 Performance & Reliability

- **Parallel Downloads** - Configurable worker pool (default: 4 workers) for faster batch operations
- **Retry Logic** - Automatic retry on transient failures (up to 3 attempts)
- **Checksum Verification** - SHA256 checksums provided for build integrity verification
- **Error Reporting** - Clear, actionable error messages for troubleshooting
